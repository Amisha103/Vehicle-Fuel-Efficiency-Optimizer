Vehicle Fuel Efficiency Optimizer

This project focuses on optimizing vehicle fuel efficiency using Random Forest for prediction and Genetic Algorithm for optimization. It helps identify the best combination of vehicle parameters to maximize fuel efficiency.

Tech Stack

Python

Random Forest

Genetic Algorithm

NumPy, Pandas, Scikit-learn

How It Works

Random Forest predicts fuel efficiency from vehicle features

Genetic Algorithm optimizes parameters to improve efficiency

How to Run
pip install -r requirements.txt
python main.py
